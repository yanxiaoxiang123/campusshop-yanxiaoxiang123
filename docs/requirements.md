# CampusShop 需求说明

校园商城教学项目。C# 版与 Java 版实现同一份需求。
**测试的期望值以本文档为准，而不是以代码的运行结果为准。**

## 1. 概述与账号

1.1 功能：登录、浏览商品、购物车、下单、查看订单、优惠券。

1.2 演示账号（密码均为 `123456`）：

| 用户名 | 说明 |
|---|---|
| alice | 普通会员，已有订单 1001 |
| bob | 银卡会员，已有订单 1002 |
| carol | 金卡会员 |

1.3 登录：

- 用户名和密码都是必填项，缺少任一项时拒绝登录（API 返回 400）。
- 用户名前后的空格忽略。
- 用户名或密码错误时提示“用户名或密码错误”（API 返回 401）。
- 登录成功返回 Token，有效期 1 小时。

1.4 金额以“元”为单位，保留 2 位小数。金额计算必须精确，不允许出现浮点误差。

## 2. 订单计价 CalculateTotal(total, level)

2.1 原价 total 的取值范围为 0 ≤ total ≤ 100000；
    超出范围时抛出参数越界异常（C#：ArgumentOutOfRangeException；Java：IllegalArgumentException）。

2.2 会员折扣（先计算）：
    普通会员 Normal：不打折
    银卡会员 Silver：9.5 折
    金卡会员 Gold  ：9 折
    折后金额四舍五入，保留 2 位小数。

2.3 满减（按折后金额计算，取最高一档，不叠加）：
    折后金额 ≥ 200：减 30
    折后金额 ≥ 100：减 10

2.4 结果四舍五入，保留 2 位小数。

2.5 ApplyDiscount(total) 只做 2.3 中的满减（把 total 当作折后金额），供购物车等旧代码使用。

2.6 【待澄清】按 2.2、2.3 计算，金卡会员在部分金额下比银卡会员付得更多
    （例：原价 110 元，金卡 99.00 元，银卡 94.50 元）。已提交产品经理确认，确认前按现有规则实现。

例：银卡会员原价 110 元：110 × 0.95 = 104.50，满 100 减 10，应付 94.50 元。

## 3. 优惠券 IsUsable(coupon, amount)

3.1 同时满足以下三个条件时，优惠券可用；任一条件不满足即不可用：

1. 未过期：今天不晚于有效期截止日（**截止日当天仍可用**）；
2. 订单金额达到使用门槛（金额 ≥ 门槛）；
3. 未被使用过。

3.2 使用优惠券 Apply(coupon, amount)：可用时，应付金额 = 订单金额 − 优惠券面额；不可用时金额不变。

3.3 每个订单最多使用一张优惠券，不可叠加。

3.4 判断有效期时，“今天”按北京时间（UTC+8）计算，与服务器所在的时区无关。

3.5 每个用户每天（北京时间）最多使用 2 张优惠券，第 3 张起拒绝使用；第二天重新计数。
    订单取消时返还当天的一次使用次数。

## 4. 下单 PlaceOrder(order)

4.1 检查库存；不足则返回“库存不足”，不得扣款。

4.2 扣减库存。

4.3 调用支付：失败 → 恢复库存，返回“支付失败”。

4.4 支付成功 → 发送下单通知：通知失败不影响订单成功，记录日志。

4.5 返回“下单成功”及订单号。

4.6 购买数量必须是 1～99 的整数，否则拒绝下单（API 返回 400）。

4.7 用户只能查看自己的订单。查看他人的订单时，API 返回 403 或 404，不得泄露他人的地址和电话。

4.8 模拟支付：单笔金额超过 5000 元时支付失败。

4.9 网页上的订单号显示为 `CS` 加数字，例如 `CS1003`。

4.10 网页购物车为空时，显示“购物车为空”，“下单”按钮不可点击。

4.11 退款 Refund(user, paid, amount)：退款金额必须大于 0，且不超过订单实付金额，否则拒绝退款；符合条件时调用支付网关退款，返回网关的结果。

## 5. 积分兑换（PRD 节选）

5.1 用户每消费 1 元获得 1 积分。

5.2 100 积分可抵扣 1 元。

5.3 积分不足时不能兑换。

5.4 积分有效期为一年。

## 附：API 一览

完整说明见网站的 Swagger 页面（C#：`/swagger`；Java：`/swagger-ui.html`）。

| 方法 | 路径 | 说明 | 需要 Token |
|---|---|---|---|
| POST | /api/auth/login | 登录 | 否 |
| GET | /api/products | 商品列表 | 否 |
| GET | /api/cart | 查看购物车 | 是 |
| POST | /api/cart/items | 加入购物车 | 是 |
| DELETE | /api/cart/items/{productId} | 移出购物车 | 是 |
| POST | /api/orders | 直接下单（单个商品） | 是 |
| GET | /api/orders | 我的订单 | 是 |
| GET | /api/orders/{id} | 订单详情 | 是 |

常用状态码：200 成功、201 已创建、400 参数错误、401 未登录或 Token 无效、402 支付失败、403 无权限、404 不存在、409 库存不足。
