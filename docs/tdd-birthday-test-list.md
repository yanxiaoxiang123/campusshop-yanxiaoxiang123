## 4. 测试锁定（deny 规则）

绿/重构阶段在 `.claude/settings.local.json` 中启用：

```json
{
  "permissions": {
    "deny": [
      "Edit(java/src/test/**)",
      "Write(java/src/test/**)"
    ]
  }
}
```

- 红阶段：允许改测试，先关闭 deny；
- 绿/重构阶段：启用 deny，只允许改 `java/src/main/**`；
- 每次提交前用 `git diff --name-only` 检查：红提交只有 `src/test`，绿/重构提交只有 `src/main`；
- 作业完成后关闭 deny，避免影响第 14 周的 BDD 测试。

实际拦截记录见 `new/作业/ppt13/04-测试锁定/`。
